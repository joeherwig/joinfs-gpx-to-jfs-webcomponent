joinfs-gpx-to-jfs

Convert a GPX tracklog into a JoinFS recording (.jfs) – everything happens in your browser. No GPX at hand? Download a synthetic sample flight and drop it below.

Try these variants

  • Aircraft preset via URL – the three aircraft fields disappear
  • Everything preset – no fields at all, converts as soon as a file is dropped
  • Force German (default: the browser's preferred languages, English as fallback)
  • Back to the default view

Language files are loaded from the folder of joinfs-gpx-to-jfs.js, so this needs to be served over http(s); opened straight from disk it stays English. The colour scheme follows your browser setting.

Embed it

<joinfs-gpx-to-jfs></joinfs-gpx-to-jfs>

<!-- preset values (fields hidden) -->
<joinfs-gpx-to-jfs icao-type="C172" callsign="ASGX" model="Cessna 172 Wheels"></joinfs-gpx-to-jfs>

<script src="joinfs-gpx-to-jfs.js"></script>
